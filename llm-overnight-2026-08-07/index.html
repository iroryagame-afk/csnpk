04什么已经计价，什么仍需证明

已经计价

  • 阿里发布日收涨 7.01%，模型“重回第一梯队”已获得第一轮定价
  • 智谱、MiniMax 已被当作高纯度 AI 资产交易，主题弹性不等于业绩确定性
  • 国产开源模型越来越便宜已是趋势，不应再给“仅开源”过高溢价

仍需证明

  • Qwen3.8‑Max 权重开放后的下载量、开发者迁移与阿里云 API 调用增量
  • 千问办公能否形成企业付费、席位增长和持续留存
  • 智谱提价后调用量与 ARR 是否继续量价齐升
  • MiniMax H3 能否拉动海外订阅、视频生成收入与毛利率

05今日交易判定

优先观察：阿里巴巴

基本面受益最直接，但发布日已经大涨。更合理的动作是等回踩承接，或等下周开源权重与 API 数据形成第二催化；不因旧闻高开追涨。

弹性观察：金山云 / 美图

受益于 Token 通胀与推理成本下降，但机制属于二阶传导。只有订单、收入、付费率或毛利率改善，才能从主题交易升级为基本面交易。

高波动：智谱 / MiniMax

短期可受国产模型情绪映射，长期却是 Qwen 与 DeepSeek 的竞争对象。若只涨估值、不涨 ARR 与毛利率，冲高回落风险高。

反向验证：金山软件 / 腾讯

OpenAI 数据显示工作场景更偏“完成任务”而非问答，强化办公与社交入口逻辑；但要看到 AI 席位、ARPU、广告或云收入，不能只看功能上线。

06证伪条件与风险

优势

中国模型已同时具备能力、开源和成本三项竞争力；应用公司获得更低推理成本，云厂获得更高 Token 消耗，产业扩散速度有望加快。

风险

价格战可能让调用量增长但收入、毛利率不增长；巨额训练投入压低自由现金流；榜单和参数规模不等于企业续费与定价权。

强化条件

Qwen 开源后开发者与 API 调用明显增加；阿里云 AI 收入加速；WPS、元宝、美图等出现可核验的付费、ARPU 或广告增量。

证伪条件

模型开放后下载和调用平淡；云收入没有跟随 Token 增长；智谱、MiniMax 调用增长但毛利率恶化，或需要持续激进融资。
